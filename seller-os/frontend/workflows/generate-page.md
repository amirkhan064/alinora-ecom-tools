# Premium Landing Page Workflow

Command: /build-premium-page

Steps:
1. Trigger **Lead Designer** to generate a premium visual wireframe map and component breakdown using the `angular-premium-design` skill.
2. Trigger **Angular SSR Engineer** to code the standalone landing page components directly into the workspace layout.
3. Trigger **Hydration QA Agent** to audit the output and automatically apply fixes if any generic layouts or SSR violations are detected.
