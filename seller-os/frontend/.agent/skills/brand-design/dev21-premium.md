# dev21-premium: Premium E-Commerce Utility Design System

## Core Mandate
- Completely destroy any generic 3-column or 4-column feature grids.
- Use an asymmetrical **Bento Grid** layout to cluster features naturally.
- Emphasize deep "anti-tarnish" premium dark slate colors (`#0B0F19`) mixed with sharp, metallic, low-opacity borders (`#2A3B56`) to give an industrial, elite utility feel.
- Fonts: High-contrast pairing. Bold, sharp headlines (`Plus Jakarta Sans`) paired with clean, monospace-accented data labels (`Inter` + `Font-Mono` for image sizes and resolution counters).

## The Four Tools Visual Guardrails
1. **Label Cropper**: Must feature a split-pane layout mimicking a 4x6 thermal shipping label getting instantly cropped and sorted by marketplace logos (Flipkart Blue, Amazon Orange, Meesho Pink).
2. **Image Cropper**: Must look like an interactive studio tool canvas highlighting 1:1 square crop boundaries.
3. **Image Downloader**: Must display a minimal asset scraping stream (simulated progress bars, payload delivery markers).
4. **AI SEO Product Listing**: Must visually show an input area translating raw seller notes into optimized, high-CTR titles and descriptions.
